# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Jekyll, deployed to GitHub Pages through GitHub Actions.

## Users

Visitors who want to read the owner's writing or follow links to portfolio work. The primary audience and primary conversion action are deliberately undecided.

## Product Purpose

A personal website that combines a blog with a directory of portfolio links.

## Capabilities and Constraints

- Blog posts are authored as Jekyll Markdown files.
- Portfolio entries can lead to dedicated pages or external destinations.
- The production custom domain is `mutnianski.dev`.
- Biography, project descriptions, and other personal copy remain Lorem Ipsum placeholders until real content is supplied.

## Evidence on Hand

No biography, project details, social profiles, testimonials, metrics, photography, or other factual portfolio material has been supplied. Future work must not fabricate these.

## Product Principles

- Keep publishing a post or portfolio link simple.
- Make writing and work equally easy to discover.
- Keep factual placeholders clearly replaceable.
- Remain compatible with GitHub Pages deployment.

## Accessibility & Inclusion

Use semantic HTML, keyboard-visible interactions, sufficient contrast, and reduced-motion behavior as baseline requirements.
